# 📊 Customer Purchase Pattern Analysis

## 📌 Project Overview
This project analyzes customer buying behavior using data analytics and machine learning techniques.

## 🎯 Objectives
- Identify purchasing trends
- Perform market basket analysis
- Segment customers using clustering

## 🛠 Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Mlxtend

## ⚙️ Features
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Association Rule Mining (Apriori Algorithm)
- Customer Segmentation (K-Means)
